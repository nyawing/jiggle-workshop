# Jiggle Workshop

Jiggle Workshop — редактор для Windows, в котором настраиваются гибкие части аксессуаров Nyawing: плащи, хвосты, ленты и подвесные украшения.

## Начало работы

Распакуйте Windows x64 ZIP из раздела релизов в отдельную папку и откройте **Jiggle Workshop.exe**. Оставьте `resources` рядом с программой: необходимые среды Python и Node уже входят в переносимую сборку.

1. Загрузите аксессуар из каталога Nyawing или Roblox. Чтобы продолжить работу, откройте сохранённый проект в формате .jiggle.json или ZIP из Jiggle Workshop.
2. Отметьте поверхность, которая должна двигаться. Поставьте начало и конец цепочки, затем добавьте промежуточные точки для изгиба.
3. Распределите веса кистью либо градиентом. При нулевом весе поверхность остаётся жёсткой; увеличение веса усиливает её движение за цепочкой.
4. Запустите симуляцию предмета или проверьте его в примерке на персонаже.
5. Для волны выберите нужную часть во вкладке костей. Включите волну ветра и укажите направление.
6. Экспортируйте результат в ZIP и загрузите его через создание аксессуаров на сайте Nyawing.

## Сборка из исходников

В каталоге приложения выполните `npm ci`, затем `npm run build`. Команда `npm test` запускает тесты логики, `npm start` открывает редактор. Проверки импортёра находятся в `tests/test_asset_io.py`.

## Лицензии

Папка `licenses` содержит условия сторонних разработчиков. Уведомления SmartBone и остальных зависимостей оставлены в исходном виде.

## Подготовка проверок исходников

Для сборки из исходников нужны Node.js/npm и Python 3. Установите Python-зависимости из `backend/requirements.txt`. Для чтения и записи двоичного RBXM положите `rbxmk.exe` в `backend/`; сторонний исполняемый файл в Source.zip не включён. Проверки интерфейса запускаются через `node tests/ui-smoke.mjs` в скрытом окне Electron.
